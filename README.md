# Wednesday Bowling Results

Golden Pin (team 13), 11th Superbowl Wednesday Trios League.

- `index.html`: interactive team hub (countdown to next match, fixtures, scores, stats, bonus).
- `golden-pin-week23.html`: simple Week 23 results page (28 Oct 2026), served at `/golden-pin-week23`.
- `vercel.json`: static-site config for Vercel (no build step).

## Deploy on Vercel

Import the repo in Vercel and deploy with the default settings: framework preset "Other", no build command, no output directory. `index.html` is served at the root.

Data comes from the league's weekly results PDF. Golden Pin data only.
